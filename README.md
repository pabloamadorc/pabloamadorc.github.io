# pabloamadorc.github.io

Personal landing page. Single page, no build step: `index.html` plus `assets/`.

- **Songs and links:** edit the `TRACKS` and `LINKS` lists at the top of the `<script>` in `index.html`.
  A track id is the part after `/track/` in a Spotify share link.
- **Where's Pablo:** edit `PLACES` (name, coordinates, zoom) and `SCHEDULE` (days 1 = Monday … 7 = Sunday, hours in Valencia time; the first matching rule wins; several places = one picked at random) in the same script.
- **Research:** edit `PAPERS` (title, authors, journal, year, DOI, TL;DR and figure) in the same script; figures live in `assets/research/`.
- **Photo:** `assets/pablo.jpg` (square).
- **Fish pattern:** `assets/peixos-color.webp`, a seamless tile of the fish illustrations; its strength is `--fish-alpha` (light and dark theme).
